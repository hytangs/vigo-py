# VIGO Python 0.4.2

Platform wheels package a headless Engine with pinned Node 24.18.0 and the Rust routing kernel. Studio and a system Node installation are unnecessary. Source installs remain lightweight and require an external compatible engine.

Route in every supported mode, ordered waypoints, supplied-traffic routing, Matrix, and Reach now reuse a bounded resident process pool per City and service date when the engine advertises support. Repeated queries reuse prepared data; results are recomputed. Older engines keep their existing supported execution paths.

Drive traffic is explicitly forwarded to the shared native Route and Matrix kernels. Engines that do not advertise this capability are rejected instead of silently dropping traffic. Query timing now includes Python request/response work for Reach as well as Route and Matrix.

Runtime selection no longer picks up sibling checkouts implicitly. Configured paths fail closed. The bundled engine strips provider credentials and runtime injection settings from its child environment. Builds verify Node archive checksums and ship a payload manifest and license notices. Installed-wheel checks run real synthetic queries in a fresh environment with an empty PATH.

API 1.0, City format 1, and Result schema 1 are unchanged. Python communicates with Node; JavaScript still owns source-row loading and itinerary object assembly. This release does not claim a fully native Python/Rust API or new field-accuracy evidence.
