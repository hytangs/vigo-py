# VIGO Python 0.3.1

This stabilization release keeps API 1.0, City format 1, and Result schema 1 unchanged.

- Select packaged runtimes on macOS, Linux, and Windows using a Studio directory or executable. The platform-independent wheel delegates to the matching native VIGO runtime.
- Reuse successful capability checks until command files change, retaining independent returned metadata.
- Require resident Matrix support, remove the one-shot fallback and retired application discovery, and read current City metadata directly.
- Explain City reuse, first-query loading, resident processes, timeouts, and timing boundaries in the Python reference.

Planned-service Scenarios apply to Reach; supplied traffic applies to Drive Route/Matrix. Live transit is available only in Studio Route. Python does not implement its own parser or routing algorithm.

Checks cover Python 3.10–3.13 on macOS, Linux, and Windows, plus public synthetic integration queries against packaged VIGO runtimes. Install the wheel or source archive here, then install the matching [VIGO 0.3.1 runtime](https://github.com/hytangs/vigo/releases/tag/v0.3.1) separately. This remains pre-release software.
