# VIGO Python 0.5.0

Use Engine 0.5 and rebuild prepared Cities with that engine. Earlier runtimes are rejected during runtime selection.

Route, Matrix, and Reach share the documented `stream` command with an explicit query kind. The private `_route-stream` protocol, one-shot fallback for older runtimes, and order-dependent JSON decoder are removed. Detailed Python Results use explicit trace output; ordinary Engine CLI and Studio responses remain compact.

Stored Results keep their original evidence. Route exports use one serialization path for all journeys, including Unicode names and full geometry precision.
